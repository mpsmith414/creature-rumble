# Credits

Creature Rumble has no downloaded art or audio: the fighters, the ring and every sound effect are generated in code.

Built with these open-source projects:

- [three.js](https://threejs.org/) for drawing (MIT)
- [Rapier](https://rapier.rs/) for physics (Apache-2.0)
- [Kokoro](https://github.com/hexgrad/kokoro) through [kokoro-js](https://github.com/hexgrad/kokoro/tree/main/kokoro.js) for
  the announcer's voice, which runs locally (Apache-2.0)
- [Hono](https://hono.dev/) for the server (MIT)
- [Vite](https://vitejs.dev/) and [Vitest](https://vitest.dev/) for building and testing (MIT)
- [qrcode](https://github.com/soldair/node-qrcode) for the join code (MIT)
- [Zod](https://zod.dev/) for checking data (MIT)

Fighters are designed with the [Anthropic API](https://docs.anthropic.com/).
